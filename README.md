# Playlist Maker

Учебное приложение, разработанное в рамках курса «Android-разработчик» на платформе Яндекс Практикум. Предназначено для формирования пользовательских плейлистов на основе медиатеки Apple iTunes. Реализована возможность прослушивания 30-секундных фрагментов аудиотреков. Приложение поддерживает светлую и тёмную темы оформления.

## Стек технологий

- **MVVM** — архитектурный паттерн
- **Room** — ORM для локальной базы данных
- **Koin** — DI (внедрение зависимостей)
- **Retrofit** — HTTP-клиент для сетевых запросов
- **Kotlin** — язык программирования
- **Coroutines** — асинхронность и потоки
- **Fragments** — модульные компоненты UI
